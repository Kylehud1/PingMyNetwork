# PingMyNetwork
Basic Network Lab that involves VLAN / DHCP / DNS / Routing / Switching
I created a basic network with a DHCP server that provided IP's to end devices on 4 different VLAN's.
I configured trunk links between the switch and routers and access links between switch and end-devices.
I created a link between the two broadcast domains connecting the two routers together so that VLAN 1 & 2 could communicate with VLAN 3 & 4.
